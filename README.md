# Awesome-Game-Development-Tools

This repository will talk about some of the pros and cons of using Notepad++, Poly Pizza, Blender, Piskel, and a few others. 

Notepad++ https://notepad-plus-plus.org/:

  Notepad++ is a free (as in “free speech” and also as in “free beer”) source code editor and Notepad replacement that supports several programming languages. Running in the MS Windows environment, its use is governed by GNU General Public License.
Based on the powerful editing component Scintilla, Notepad++ is written in C++ and uses pure Win32 API and STL which ensures a higher execution speed and smaller program size. By optimizing as many routines as possible without losing user friendliness, Notepad++ is trying to reduce the world carbon dioxide emissions. When using less CPU power, the PC can throttle down and reduce power consumption, resulting in a greener environment.

Pros: 
- Lightweight and Fast: It opens instantly and uses very little computer memory, even with large files.
- Tabbed Interface: You can open and work on multiple documents at the same time in separate tabs.
- Syntax Highlighting: It color-codes text for over 80 programming and markup languages.
- Powerful Search and Replace: It supports regular expressions (regex) to find and fix text across huge files quickly.
- Session Memory: It remembers your open tabs and unsaved changes even if you close the program or restart your computer.
- Extensible: You can add plugins for extra tools like code formatters and custom themes. 

Cons: 
- Windows Only: It runs natively only on Windows, which is frustrating if you use a Mac or Linux.
- Outdated Interface: The visual design looks old and less polished compared to modern editors.
- Not an IDE: It lacks advanced Integrated Development Environment features like built-in code debugging, integrated terminals, and deep project management.
- No Cloud Sync: It does not have built-in cloud integration to sync your files or settings across multiple devices.
- Overwhelming for Beginners: The vast number of menus and technical settings can confuse casual users who just want a basic notepad.

Poly Pizza https://poly.pizza/: 

Poly Pizza is a free online library and search engine for low-poly 3D models, hosting more than 10,700 hand-picked models for games, AR/VR experiences, and web projects. The platform lets visitors browse, preview, and download models directly with no account or login required.

Pros:
- Completely free with no account or download limits
- Large, hand-curated catalogue of game-ready low-poly models
- Clear per-model license badges (CC0 vs CC-BY)
- Direct .glb downloads that work in Unity, Unreal, Godot, and browsers
- Actively maintained by its creator since 2021

Cons/Limitations: 
- License varies per model — CC-BY models require attribution, so you must check each one
- Quality and style are inconsistent since models come from many different artists
- Low-poly only; no high-poly or photorealistic content
- No bulk download or full-catalogue export option
- As a solo-run indie project, support and moderation are limited 

Blender https://www.blender.org/: 

	Blender is a 3D computer graphics software. It’s open-source, meaning it’s publicly accessible. For this reason, updates are handled by the community that uses Blender, rather than a third party, a specific team, or Blender itself. This often results in bug fixes, new features, and usability improvements happening quicker than with traditional software.

Pros: 
It’s free and open-source software
It’s more diverse than most 3D programs
Blender software uses procedural workflow
The development cycle is wild. Due to its open-source nature, you'll often find a new version of Blender every few months. You can even download the source code for your Blender software and create your own version, if you know how to write code with Python.

Cons: 
It isn’t industry standard. Blender software is great for learning the ropes and working on solo projects, whether they’re paid gigs or just for fun. However, if you take on a project and join someone’s team, it’s unlikely they’ll use Blender for 3D animation. This is because companies usually have paid-for animation programs that work alongside their other processes.
It has a steep learning curve
It can be buggy. Since it’s open-source, bugs and weird things can crop up from time to time. If that happens, it’s down to someone in the community to fix the problem!
Blender software struggles on old devices. Blender recommends devices no older than 10 years, but not everyone has the luxury of a new computer

Piskel https://www.piskelapp.com/: 
	Piskel is a free, open-source editor for creating pixel art and animated sprites. You can run it directly in a desktop web browser or download offline desktop versions

Pros: 
Completely free and open-source. You can use the full tool without trials or paywalls, and explore its codebase on GitHub 
Browser and offline access. You can launch it instantly in a web browser with zero setup, or download the desktop app for offline use on Windows, macOS, and Linux
Beginner-friendly interface. The clean layout includes essential pixel art tools—such as onion skinning, layers, symmetry pens, and dithering—without overwhelming new users
Live animation preview. A real-time preview window updates as you draw, letting you adjust frame delays on the fly
Flexible export options. You can export work as animated GIFs, PNG sprite sheets, or .piskel project files
Cons: 
No built-in cloud saving. Browser work only saves locally to your browser's cache, meaning clearing your cache or closing a tab without manually exporting will permanently erase your progress
Performance and canvas limits. Users on Reddit agree that Piskel struggles with animations over 100 frames or canvases larger than 250×250 pixels, often showing visual artifacts at high resolutions
Undo stability issues. According to user reports on the GDevelop Forum, pressing Ctrl+Z multiple times in a row can cause the editor screen to turn completely white, forcing a restart and risking lost work
Basic toolset and brush limits. Brushes are restricted to 1×1 through 4×4 pixel squares, and it lacks advanced features like adjustment layers or scripting

CRYENGINE https://www.cryengine.com/: 
	CRYENGINE is a game engine developed by Crytek known for photorealistic visuals, large outdoor environments, and first-person shooters.

Pros:
Visual fidelity and environments: Excels at realistic lighting, volumetric effects, water simulation, vegetation bending, and large open-world or outdoor terrain
Strong FPS and physics roots: Built with first-person shooters and interactive destruction/physics in mind
Source code and editor tools: Offers access to engine and editor source code along with integrated world-building tools
Accessible entry pricing: Has historically offered free entry with royalty thresholds (such as a 5% royalty after the first $5,000 in annual project revenue), lowering upfront barriers for small teams
Cons: 
Steep learning curve: Less intuitive for beginners, often requiring C++ familiarity and heavier hardware 
Smaller community and documentation: Fewer tutorials, community guides, and third-party marketplace assets make troubleshooting slower
Lower adoption and talent pool: Far fewer developers specialize in CRYENGINE, which can complicate hiring and long-term support
Niche fit and update concerns: Best suited for specific genres and environments, while Crytek's financial ups and downs and slower public release cadence raise questions about long-term external momentum 

Autodesk Maya https://www.autodesk.com/products/maya/overview: 
	Autodesk Maya is an industry-standard 3D animation, modeling, simulation, and rendering application widely used in film, television, visual effects (VFX), and video game production. Developed originally by Alias and acquired by Autodesk in 2005, it is favored by large production studios for its deep animation and rigging toolsets and pipeline extensibility

Pros:
Industry-standard status: Widely adopted across major animation, VFX, and AAA game studios, making it a common requirement for studio pipeline jobs
Animation and rigging strength: Offers mature keyframe controls, a capable graph editor, rigging tools, and simulation features
Pipeline extensibility: Supports customization and workflow automation through scripting languages like Python and MEL, plus third-party plug-ins and rendering engines 
Comprehensive 3D feature set: Covers modeling (polygonal and NURBS), UV mapping, animation, dynamics, lighting, and rendering within a single production environment
Cons: 
High cost: Paid subscription pricing can be steep for independent artists, hobbyists, and small studios compared to free or lower-cost tools
Steep learning curve: Dense menus, numerous tools, node/hierarchy concepts, and legacy feature sets can overwhelm beginners
Hardware demands: Heavy scenes and simulations require strong PC hardware and can lag on underpowered systems
Stability and bugs: Reviewers on Software Advice, G2, and PCMag note occasional crashes, stability issues, and clutter from multiple windows or menus

Krita https://krita.org/en/: 
	Krita is a painting and 2D animation software designed for artists and animators that’s both free and open-source. The absence of licensing fees makes Krita ideal for indie devs, hobbyists and studios on a limited budget.

Pros:
Free and open-source: No subscription fees or licensing costs across Windows, macOS, Linux, Android, and ChromeOS
Strong brush engine: Includes over 100 customizable default brushes, easy brush editing, and colorize/layering tools tailored to digital painters and illustrators
Customizable workspace: Dockers, workspaces, and shortcuts can be tailored for painting, comics, or 2D animation, with PSD file support and plugin options
Built-in 2D animation and texture tools: Supports basic frame-by-frame animation and 3D texture work without needing a separate paid app
Cons: 
Learning curve and cluttered UI: Beginners often find the interface dense, and workflows like clipping masks or text/lettering can feel less intuitive than in rival apps
Performance and memory limits: Large canvases, heavy brush strokes, and complex projects can cause lag, high RAM usage, or large file sizes
Narrower scope than specialized tools: Photo manipulation, vector graphics, and advanced animation features are lighter than in dedicated tools
No official paid support: Relies on community forums, documentation, and volunteers rather than dedicated customer support

Wwise https://www.audiokinetic.com/en/wwise/overview: 
	Wwise is middleware that connects to game engines to activate sound effects and music instead of running them through the engine. Devs create sound effects in a Digital Audio Workspace (DAW) and put them into Wwise, which defines what triggers each sound effect in-game. Wwise determines when to play the crunchy gravel footstep sound instead of the grassy field one. Wwise was founded in 2009 and acquired by Sony Interactive Entertainment in 2019. It’s currently maintained by the Audiokinetic software devs and has been used in AAA games like Halo.

Pros:
Deep dynamic and interactive audio: Supports states, switches, RTPCs (Real-Time Parameter Controls), interactive music, and spatial audio workflows. It improves audio management, profiling, and dynamic audio setup over native engine tools like Unity's built-in system.
Designer workflow independence: Separates content/behavior hierarchies from events and lets sound designers build and tweak audio behavior with less constant programmer intervention—though complex hooks still require code
File reuse and compression control: Lets teams reuse source assets across variations and tune compression when generating SoundBanks to balance audio quality and build size
Industry adoption and training: Widely used in AAA game development and supported by Audiokinetic tutorials, and WAAPI (Wwise Authoring API)
Cons: 
Steep learning curve: Its hierarchical, logic-driven interface feels abstract compared to timeline-based DAWs or simpler tools, and users without a programming background often find it challenging at first
Overhead for simple projects: Small games with basic sound playback or teams comfortable with native engine tools may find an extra authoring and runtime layer unnecessary
Licensing and workflow constraints: Commercial game licensing depends on production budget and target platforms, and specific UI/workflow details—such as managing Work Units or lacking direct fade-in/fade-out on certain sources/containers outside events—can take adjustment

Machinations https://machinations.io/: 
	Machinations is a visual flowchart and simulation tool used to model, balance, and test game economies and resource-flow systems without building a full prototype first. Its value depends heavily on how complex your game's economy is and how you plan to use the model in production.

Pros:
Tests complex economies and RNG early: Lets you simulate resource flows, feedback loops, and probability (such as loot drops or Monte Carlo runs) before writing game code
Faster iteration than spreadsheets: Handles dynamic feedback loops and multi-step simulations more visually and flexibly than static spreadsheets
Clearer team alignment: Gives designers, engineers, and stakeholders a shared diagram to see how systems behave and interact
Browser-based with reusable building blocks: Runs in the browser and supports reusable components, custom logic, and simulation templates
Cons: 
Can feel like redundant work: Many systems still need to be rebuilt or translated inside your game engine, which can feel like extra effort for simpler mechanics
Learning curve and "fiddly" logic: Modeling complex rules, node behaviors, and formulas takes practice and can feel low-level or tedious
Free tier and simulation limits: Free usage restricts diagram size or simulation credits/events, which can get tight as diagrams grow or run large batch simulations
Limited to system logic, not "game feel": It models numbers, rules, and flows—not player feel, controls, visuals, or spatial gameplay

Audacity https://www.audacityteam.org/: 
	Audacity is a DAW geared for adjusting noise levels, applying different effects and letting devs export in multiple formats. Even though it’s a DAW, Audacity is used to edit existing audio files. DAWs like Reaper create audio from scratch, so devs record audio or write music with MIDI, making them ideal for full sound production instead. Audacity was developed by the Audacity Team with current maintenance by Muse Group and is completely free and open-source. Its accessibility makes it ideal for indie devs, students and hobbyists. Games like Celeste and Undertale used Audacity to edit dialogue clips and add retro-style sound effects.

Pros:
Free and open source: Costs nothing to download or use, making it accessible for beginners, hobbyists, and podcasters
Cross-platform and lightweight: Runs on Windows, macOS, and Linux with modest system requirements
Broad format and plugin support: Exports to common formats like WAV, MP3, FLAC, and Ogg Vorbis (plus additional formats via FFmpeg) and supports third-party effects and plugins. According to PCMag, it supports audio up to 32-bit/384kHz and includes tools like noise reduction, compression, and Smart Clips
Useful editing and analysis tools: Offers multi-track editing, spectrogram views, and raw data recovery for certain corrupted files. As noted in Software Advice, users also appreciate simplified project backups with fewer individual files
Cons: 
Lacks full DAW depth: Less suited for complex music production or heavy multitrack mixing compared to tools like Pro Tools, Cubase, or Adobe Audition
Interface and workflow quirks: Many users find the interface dated, effect previews slow, and certain workflows less intuitive than in commercial editors
Missing features and version gaps: Lacks built-in remote recording and official mobile apps, and users note fewer AI tools. Reviews of Audacity 4 also highlight missing features carried over from earlier releases as well as early accessibility issues
Community-driven support: Relies on community resources and documentation rather than dedicated enterprise or phone support
